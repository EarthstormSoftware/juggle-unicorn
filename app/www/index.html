Restart and Reset

Reset puts every setting on these pages back to its default (the web password too). A factory reset also makes the Pi forget its name, Wi-Fi and SSH keys, and start in setup mode as a new Pi.

Topics

{name} becomes the device name. Topics no longer used are cleared from the broker after the restart.

Group

Devices with the same group name follow each other: turn one on, or change its mode or colour, and the rest do the same (PlasmaSticks too). A mode another device doesn't have is ignored by it. Letters, digits, - and _.

Home Assistant

Home Assistant adds the light automatically (MQTT discovery), with an Alert button and an Alerts switch. Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.

Clock

The clock is the Pi's, set from the internet; summer time follows the time zone. The time zone was first set when the card was flashed.

Location

For sunrise and sunset events. East and north are positive.

Events

Up to 8. Events act like any other change, so a group follows them. After a restart the light does what the latest event said.

Alerts

With alerts on, an alert interrupts whatever the light is doing, even when it's off: it flashes, then the light carries on as it was. Alerts come from the topic watched below, Home Assistant's Alert button, MQTT (<base>/alert) or the API (POST /api/alert).

The Alert

Each flash is on, then off, for these times (off 0: steady).

Watch

Another device's topic, such as a motion sensor's /home/device/pir/state: an alert starts when it says something has happened (motion true, ON, true, or any other message), once until it clears. Needs MQTT.
